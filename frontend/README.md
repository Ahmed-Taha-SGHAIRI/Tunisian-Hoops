# Tunisian Hoops

An independent frontend application for following Tunisian basketball (fixtures, results, standings, teams, players, transfers, news).

## Setup

1. Install dependencies:
   ```bash
   pnpm install
   ```
2. Run development server:
   ```bash
   pnpm dev
   ```

## Workspace Structure
- `apps/web`: Next.js frontend application.
- `packages/shared`: Shared TypeScript domain types and constants.
